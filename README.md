# yarmed-preview

Превью нового сайта yarmed.com для согласования с клиентом. Страницы закрыты от поисковиков.

**Главная ссылка:** https://ilyasorokin94-hue.github.io/yarmed-preview/ — финальная сборка всего сайта (каталог, бренды, карточки, услуги).
Собирается в репозитории `yarmed-site`: `python3 preview/sayt/build.py`, затем `python3 preview/publish_final.py ПАПКА_ЭТОГО_РЕПОЗИТОРИЯ`. Здесь руками не правим.

- [Архив прежних версий](arhiv/): сайт 16.11, главные 11–13.11, макеты главной.
- Старые адреса `sayt/` и `sayt-2611/` переадресуют на те же страницы финальной сборки.
- `start/` и `home-v4-film/`: общие картинки и фильм, на них ссылаются все версии.
